# Публичное оформление Яндекс ID

Это отдельный от developer setup этап, не условие локальных mocked тестов.

По [документации регистрации Яндекс ID](https://yandex.ru/dev/id/doc/ru/register-auth) пользователь видит название и иконку сервиса в согласии и списке доступов. Для неверифицированного сервиса возможно предупреждение. До широкой публикации владелец проверяет требования Яндекса к верификации сервиса и оформляет необходимые публичные страницы/иконку через отдельный deployment/branding review. Эта задача не создаёт политики и не публикует юридические тексты.

Технический доступ Wipster ограничен `login:email`. Базовые id/client_id/login приходят без дополнительного profile scope. Пользователь может отозвать согласие в Яндекс ID «Доступы к данным»; это отдельно от выхода из Wipster, отзывающего сессию устройства.
